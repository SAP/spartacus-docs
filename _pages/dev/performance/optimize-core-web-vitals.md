# Optimize Core Web Vitals

In your custom Spartacus storefront you should follow Google's guidelines on optimizing Core Web Vitals, which are the key metrics for measuring the user experience of your web application. Moreover, Spartacus provides a set of features to help you achieve good Core Web Vitals metrics by default.
